  1. 01

    Installez l'extension

    Ajoutez offline.translator à Chrome en un clic. Aucun compte. Aucune inscription. Aucune autorisation au-delà du nécessaire.

Conçu pour les développeurs, les chercheurs et tous ceux qui lisent le web dans une seconde langue.

Traduction sur l'appareil

Chaque phrase est traduite par la Translator API intégrée à Chrome, exécutée sur votre appareil. La traduction se fait dans le navigateur, ce qui aide à éviter d'envoyer le texte de la page vers un service de traduction externe.

your pageno serverTranslator API ● local

Suivi en temps réel

Suivez la progression de la traduction en direct avec un pourcentage précis et un détail par segment. Passez à tout moment entre les modes Viewport (rapide) et All (page complète).

212 / 49643% ● viewport

Cache de traduction intelligent

Les traductions sont stockées dans IndexedDB et réutilisées instantanément lors des visites suivantes. Le contenu répété comme les menus et les pieds de page n'est traduit qu'une fois, puis servi depuis le cache, sans appel API supplémentaire.

IndexedDBcache hit ● 0 ms

Optimisation IA (Gemini)

Post-traitez les traductions avec la Prompt API de Chrome. Choisissez entre les styles Professional, Casual ou Concise. Le texte optimisé est enregistré dans le cache pour une réutilisation immédiate.

v1 casualv2 Professional ●

Pour qui

Pensé pour celles et ceux qui lisent le web dans plus d'une langue

Développeurs

Lisez de la documentation étrangère, des discussions Stack Overflow et des blogs techniques sans copier-coller dans un service de traduction. Le code sensible et les documents internes restent hors des serveurs externes.

Chercheurs et universitaires

Traduisez des articles, des publications et des sources académiques entières sans quitter la page. La couche de glossaire garantit une traduction cohérente des termes spécialisés.

Utilisateurs soucieux de leur vie privée

Parcourez l'actualité internationale, les réseaux sociaux et les communications personnelles sans envoyer vos habitudes de lecture ni votre contenu privé à des API de traduction tierces.

Équipes internationales

Consultez des sites concurrents, de la documentation partenaire ou du contenu client dans n'importe quelle langue sans lancer un flux de traduction séparé.

FAQ

Questions fréquentes

offline.translator traduit des pages web entières directement dans votre navigateur Chrome avec la Translator API intégrée à Chrome. La traduction est traitée dans Chrome sur votre appareil, au lieu de passer par un service de traduction externe. Ouvrez le panneau latéral, choisissez une langue cible, et l'extension traduit progressivement le texte visible pendant le défilement.
Oui. offline.translator est actuellement gratuit à l'usage. À ce jour, il n'y a ni offre payante, ni abonnement, ni exigence d'API key.
offline.translator nécessite Chrome 138 ou version ultérieure sur ordinateur. Il utilise la Translation API et la Prompt API intégrées à Chrome, qui ne sont pas disponibles dans les autres navigateurs. La prise en charge d'autres navigateurs pourra être ajoutée plus tard.
De nombreux outils de traduction dans le navigateur envoient le contenu de la page à un service distant pour traitement. offline.translator traite la traduction dans Chrome avec l'IA sur l'appareil, tout en proposant un cache intelligent, une optimisation IA, une couche de glossaire personnalisée et des contrôles de viewport page par page.
offline.translator est conçu pour traiter la traduction dans Chrome sur votre appareil plutôt que via un service de traduction externe. Cette approche peut bien convenir aux wikis internes, aux documents confidentiels, aux e-mails personnels et aux sessions de navigation privée.
offline.translator prend en charge 39 langues, dont l'arabe, le bulgare, le bengali, le tchèque, le danois, l'allemand, le grec, l'anglais, l'espagnol, le finnois, le français, l'hindi, le croate, le hongrois, l'indonésien, l'italien, l'hébreu, le japonais, le kannada, le coréen, le lituanien, le marathi, le néerlandais, le norvégien, le polonais, le portugais, le roumain, le russe, le slovaque, le slovène, le suédois, le tamoul, le télougou, le thaï, le turc, l'ukrainien, le vietnamien, le chinois et le chinois traditionnel.
Après la traduction initiale, vous pouvez utiliser la Prompt API de Chrome (Gemini Nano) pour post-traiter les traductions. Choisissez Professional pour un registre formel, Casual pour un ton conversationnel naturel, ou Concise pour une sortie plus courte. Les traductions optimisées sont réenregistrées dans le cache, vous ne payez donc pas deux fois le coût d'optimisation. Cette fonctionnalité nécessite que la Prompt API soit disponible sur votre machine.
