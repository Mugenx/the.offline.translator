FAQ

Frequently asked questions

offline.translator translates entire webpages directly in your Chrome browser using Chrome's built-in Translator API. Translation is processed in Chrome on your device instead of through an external translation service. Open the side panel, pick a target language, and the extension progressively translates visible text as you scroll.
Yes. offline.translator is free to use. There are currently no paid tiers, subscriptions, or API key requirements.
offline.translator requires Chrome 138 or newer on desktop. It uses Chrome's built-in Translation API and Prompt API which are not available in other browsers. Support for additional browsers may be added in the future.
Many browser translation tools route page content through a remote service for processing. offline.translator handles translation in Chrome using on-device AI, and also includes smart caching, AI optimization (Professional/Casual/Concise styles), a custom glossary layer, and per-page viewport controls.
offline.translator is designed to handle translation in Chrome on your device instead of through an external translation service. That workflow can be a good fit for internal company wikis, confidential documents, personal email, and private browsing sessions.
offline.translator supports over 40 languages including Arabic, Bulgarian, Bangla, Czech, Danish, German, Greek, English, Spanish, Finnish, French, Hindi, Croatian, Hungarian, Indonesian, Italian, Hebrew, Japanese, Kannada, Korean, Lithuanian, Marathi, Dutch, Norwegian, Polish, Portuguese, Romanian, Russian, Slovak, Slovenian, Swedish, Tamil, Telugu, Thai, Turkish, Ukrainian, Vietnamese, Chinese, and Traditional Chinese.
After the initial translation, you can use Chrome's Prompt API (Gemini Nano) to post-process translations. Choose Professional for formal language, Casual for a natural conversational tone, or Concise for shorter output. Optimized translations are saved back to the cache so repeated content can be reused without rerunning the same optimization. This feature requires Prompt API availability on your machine.
