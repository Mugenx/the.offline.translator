الأسئلة الشائعة

يترجم offline.translator صفحات الويب كاملة مباشرة داخل متصفح Chrome باستخدام Translator API المدمجة في Chrome. تتم الترجمة داخل Chrome على الجهاز بدلاً من الاعتماد على خدمة ترجمة خارجية. افتح اللوحة الجانبية، واختر اللغة المستهدفة، وسيبدأ الامتداد في ترجمة النص الظاهر تدريجيًا أثناء التمرير.
نعم. يمكن استخدام offline.translator مجانًا حاليًا. لا توجد في الوقت الحالي خطط مدفوعة أو اشتراكات أو متطلبات API key.
يتطلب offline.translator Chrome 138 أو أحدث على أجهزة الكمبيوتر. فهو يعتمد على Translation API و Prompt API المدمجين في Chrome، وهما غير متاحين في المتصفحات الأخرى. وقد يُضاف دعم لمتصفحات أخرى مستقبلًا.
تقوم كثير من أدوات الترجمة في المتصفح بتمرير محتوى الصفحة إلى خدمة بعيدة للمعالجة. أما offline.translator فيعالج الترجمة داخل Chrome باستخدام الذكاء الاصطناعي على الجهاز، مع التخزين المؤقت الذكي وتحسينات AI وطبقة مصطلحات مخصصة وتحكم على مستوى الجزء الظاهر من الصفحة.
صُمم offline.translator لمعالجة الترجمة داخل Chrome على جهازك بدلًا من الاعتماد على خدمة ترجمة خارجية. ويمكن أن يكون هذا الأسلوب مناسبًا للويكي الداخلية، والمستندات الحساسة، والبريد الشخصي، وجلسات التصفح الخاصة.
يدعم offline.translator 39 لغة، منها العربية والبلغارية والبنغالية والتشيكية والدنماركية والألمانية واليونانية والإنجليزية والإسبانية والفنلندية والفرنسية والهندية والكرواتية والمجرية والإندونيسية والإيطالية والعبرية واليابانية والكانادا والكورية والليتوانية والماراثية والهولندية والنرويجية والبولندية والبرتغالية والرومانية والروسية والسلوفاكية والسلوفينية والسويدية والتاميلية والتيلوغوية والتايلاندية والتركية والأوكرانية والفيتنامية والصينية والصينية التقليدية.
بعد الترجمة الأولية، يمكنك استخدام Prompt API في Chrome ‏(Gemini Nano) لمعالجة الترجمة لاحقًا. اختر Professional للغة الرسمية، أو Casual لأسلوب محادثة طبيعي، أو Concise لمخرجات أقصر. وتُحفَظ الترجمات المحسّنة في الذاكرة المؤقتة، لذلك لن تدفع تكلفة التحسين مرتين للمحتوى نفسه. تتطلب هذه الميزة توفر Prompt API على جهازك.
