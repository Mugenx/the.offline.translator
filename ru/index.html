Как это работает

Готово за 30 секунд

Установите один раз, откройте боковую панель, выберите язык. Перевод начинается сразу и успевает за прокруткой.

Читать руководство
Настроить один разКаждая страница
  1. 01

    Установите расширение

    Добавьте offline.translator в Chrome в один клик. Без аккаунта. Без регистрации. Без лишних разрешений.

  2. 02

    Откройте боковую панель

    Нажмите на значок расширения, чтобы открыть боковую панель. Выберите целевой язык в списке To — и все готово.

  3. 03

    Читайте на своем языке

    Перевод начинается сразу и работает в фоновом режиме. Следите за индикатором прогресса и прокручивайте страницу, чтобы постепенно переводить новый контент.

Перевод на устройстве

Каждое предложение переводится с помощью встроенного Translator API Chrome на вашем устройстве. Перевод выполняется в браузере и помогает не передавать текст страницы внешнему сервису перевода.

your pageno serverTranslator API ● local

Отслеживание прогресса в реальном времени

Следите за ходом перевода по точному проценту и разбивке по сегментам. В любой момент переключайтесь между режимами Viewport (быстро) и All (вся страница).

212 / 49643% ● viewport

Умный кэш переводов

Переводы сохраняются в IndexedDB и мгновенно используются повторно при следующем посещении. Повторяющийся контент, например меню и футеры, переводится один раз и затем отдается из кэша — без дополнительных API-вызовов.

IndexedDBcache hit ● 0 ms

ИИ-оптимизация (Gemini)

Дорабатывайте переводы с помощью Prompt API в Chrome. Доступны стили Professional, Casual и Concise. Оптимизированный текст сохраняется обратно в кэш для мгновенного повторного использования.

v1 casualv2 Professional ●

Кто использует

Создано для тех, кто читает веб более чем на одном языке

Разработчики

Читайте документацию на иностранных языках, треды Stack Overflow и технические блоги без копирования в сервис перевода. Чувствительный код и внутренние документы не уходят на внешние серверы.

Исследователи и академические пользователи

Переводите целые научные статьи, публикации и академические источники, не покидая страницу. Слой глоссария обеспечивает единообразный перевод терминов предметной области.

Пользователи, ценящие приватность

Читайте международные новости, соцсети и личную переписку, не отправляя свои привычки чтения и личный контент в сторонние переводческие API.

FAQ

Часто задаваемые вопросы

offline.translator переводит веб-страницы целиком прямо в браузере Chrome с помощью встроенного Translator API Chrome. Перевод обрабатывается в Chrome на вашем устройстве, а не через внешний сервис перевода. Откройте боковую панель, выберите целевой язык, и расширение будет постепенно переводить видимый текст по мере прокрутки.
Да. Сейчас offline.translator можно использовать бесплатно. На данный момент нет платных тарифов, подписок или требований к API key.
Для offline.translator требуется Chrome 138 или новее на компьютере. Он использует встроенные Translation API и Prompt API Chrome, которые недоступны в других браузерах. В будущем может появиться поддержка дополнительных браузеров.
Многие инструменты браузерного перевода отправляют содержимое страницы в удаленный сервис для обработки. offline.translator обрабатывает перевод в Chrome с помощью ИИ на устройстве и также включает умный кеш, AI-оптимизацию, пользовательский слой глоссария и управление областью просмотра для каждой страницы.
offline.translator спроектирован так, чтобы обрабатывать перевод в Chrome на вашем устройстве, а не через внешний сервис перевода. Такой подход может хорошо подойти для внутренних wiki, конфиденциальных документов, личной почты и приватных сессий браузера.
offline.translator поддерживает 39 языков, включая арабский, болгарский, бенгальский, чешский, датский, немецкий, греческий, английский, испанский, финский, французский, хинди, хорватский, венгерский, индонезийский, итальянский, иврит, японский, каннада, корейский, литовский, маратхи, нидерландский, норвежский, польский, португальский, румынский, русский, словацкий, словенский, шведский, тамильский, телугу, тайский, турецкий, украинский, вьетнамский, китайский и традиционный китайский.
После первоначального перевода вы можете использовать Prompt API Chrome (Gemini Nano) для постобработки переводов. Выберите Professional для формального стиля, Casual для естественного разговорного тона или Concise для более короткого результата. Оптимизированные переводы снова сохраняются в кэш, поэтому вам не придется платить стоимость оптимизации дважды за один и тот же контент. Для этой функции требуется доступность Prompt API на вашем устройстве.
