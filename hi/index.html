FAQ

अक्सर पूछे जाने वाले सवाल

offline.translator आपके Chrome ब्राउज़र में Chrome की built-in Translator API का उपयोग करके पूरे वेबपेज का अनुवाद करता है। अनुवाद आपके डिवाइस पर Chrome के भीतर प्रोसेस होता है, किसी बाहरी translation service के ज़रिए नहीं। साइड पैनल खोलें, target language चुनें, और एक्सटेंशन स्क्रॉल करते समय दिखने वाले टेक्स्ट का क्रमिक अनुवाद करता रहेगा।
हाँ। offline.translator अभी free to use है। फिलहाल इसमें कोई paid tier, subscription या API key requirement नहीं है।
offline.translator के लिए डेस्कटॉप पर Chrome 138 या नया चाहिए। यह Chrome के बिल्ट-इन Translation API और Prompt API का उपयोग करता है, जो दूसरे ब्राउज़र में उपलब्ध नहीं हैं। भविष्य में अतिरिक्त ब्राउज़र सपोर्ट जोड़ा जा सकता है।
कई browser translation tools पेज कंटेंट को प्रोसेसिंग के लिए किसी remote service तक भेजते हैं। offline.translator Chrome के भीतर on-device AI से translation करता है, और साथ में smart cache, AI optimization, custom glossary layer और per-page viewport controls भी देता है।
offline.translator को इस तरह बनाया गया है कि translation आपके डिवाइस पर Chrome के भीतर हो, न कि किसी बाहरी translation service के ज़रिए। यह तरीका internal wiki, confidential documents, personal email और private browsing sessions के लिए बेहतर fit हो सकता है।
offline.translator 39 भाषाओं का समर्थन करता है, जिनमें अरबी, बुल्गारियाई, बांग्ला, चेक, डैनिश, जर्मन, ग्रीक, अंग्रेज़ी, स्पेनिश, फ़िनिश, फ़्रेंच, हिंदी, क्रोएशियाई, हंगेरियन, इंडोनेशियाई, इतालवी, हिब्रू, जापानी, कन्नड़, कोरियाई, लिथुआनियाई, मराठी, डच, नॉर्वेजियन, पोलिश, पुर्तगाली, रोमानियाई, रूसी, स्लोवाक, स्लोवेनियाई, स्वीडिश, तमिल, तेलुगु, थाई, तुर्की, यूक्रेनी, वियतनामी, चीनी और पारंपरिक चीनी शामिल हैं।
शुरुआती अनुवाद के बाद, आप Chrome के Prompt API (Gemini Nano) का उपयोग करके अनुवाद को बाद में बेहतर बना सकते हैं। Professional औपचारिक भाषा के लिए, Casual स्वाभाविक बातचीत वाले अंदाज़ के लिए, और Concise छोटे आउटपुट के लिए चुनें। ऑप्टिमाइज़ किए गए अनुवाद फिर से कैश में सेव हो जाते हैं, इसलिए आपको उसी सामग्री पर दोबारा ऑप्टिमाइज़ेशन लागत नहीं देनी पड़ती। इस सुविधा के लिए आपके सिस्टम पर Prompt API उपलब्ध होना चाहिए।
