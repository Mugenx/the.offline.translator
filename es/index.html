Traducción en el dispositivo

Cada frase se traduce con la Translator API integrada de Chrome en tu dispositivo. La traducción se realiza dentro del navegador, lo que ayuda a evitar enviar el texto de la página a un servicio de traducción externo.

Seguimiento en tiempo real

Sigue el progreso de la traducción al instante con un porcentaje preciso y desglose por segmentos. Cambia entre los modos Viewport (rápido) y All (página completa) cuando quieras.

212 / 49643% ● viewport

Caché inteligente de traducción

Las traducciones se guardan en IndexedDB y se reutilizan al instante cuando vuelves. El contenido repetido, como menús y pies de página, se traduce una vez y luego se sirve desde la caché, sin llamadas extra a la API.

IndexedDBcache hit ● 0 ms

Optimización con IA (Gemini)

Postprocesa las traducciones con la Prompt API de Chrome. Elige entre estilos Professional, Casual o Concise. El texto optimizado se guarda de nuevo en la caché para reutilizarlo al instante.

v1 casualv2 Professional ●

Quién lo usa

Pensado para quienes leen la web en más de un idioma

Desarrolladores

Lee documentación en otros idiomas, hilos de Stack Overflow y blogs técnicos sin copiar y pegar en un servicio de traducción. El código sensible y los documentos internos se mantienen lejos de servidores externos.

Investigadores y académicos

Traduce artículos, papers y fuentes académicas completas sin salir de la página. La capa de glosario garantiza que los términos específicos del dominio se traduzcan de forma consistente.

Usuarios preocupados por la privacidad

Navega por noticias internacionales, redes sociales y comunicaciones personales sin enviar tus hábitos de lectura ni tu contenido privado a APIs de traducción de terceros.

Equipos globales

Revisa sitios de la competencia, documentación de socios o contenido para clientes en cualquier idioma sin montar un flujo de traducción aparte.

FAQ

Preguntas frecuentes

offline.translator traduce páginas web completas directamente en tu navegador Chrome usando la Translator API integrada de Chrome. La traducción se procesa dentro de Chrome en tu dispositivo en lugar de pasar por un servicio de traducción externo. Abre el panel lateral, elige un idioma de destino y la extensión irá traduciendo el texto visible mientras te desplazas.
Sí. offline.translator se puede usar gratis en este momento. Actualmente no hay planes de pago, suscripciones ni requisitos de API key.
offline.translator requiere Chrome 138 o superior en escritorio. Usa la Translation API y la Prompt API integradas de Chrome, que no están disponibles en otros navegadores. Es posible que en el futuro se añada compatibilidad con más navegadores.
Muchas herramientas de traducción del navegador envían el contenido de la página a un servicio remoto para procesarlo. offline.translator procesa la traducción dentro de Chrome con IA en el dispositivo y además ofrece caché inteligente, optimización con IA, una capa de glosario personalizada y controles por viewport en cada página.
offline.translator está diseñado para procesar la traducción dentro de Chrome en tu dispositivo, en lugar de depender de un servicio de traducción externo. Ese flujo puede encajar bien con wikis internos, documentos confidenciales, correos personales y sesiones de navegación privada.
offline.translator admite 39 idiomas, entre ellos árabe, búlgaro, bengalí, checo, danés, alemán, griego, inglés, español, finés, francés, hindi, croata, húngaro, indonesio, italiano, hebreo, japonés, canarés, coreano, lituano, maratí, neerlandés, noruego, polaco, portugués, rumano, ruso, eslovaco, esloveno, sueco, tamil, télugu, tailandés, turco, ucraniano, vietnamita, chino y chino tradicional.
Después de la traducción inicial, puedes usar la Prompt API de Chrome (Gemini Nano) para postprocesar las traducciones. Elige Professional para lenguaje formal, Casual para un tono conversacional natural, o Concise para una salida más corta. Las traducciones optimizadas se guardan de nuevo en la caché, así que no pagas el coste de optimización dos veces. Esta función requiere que la Prompt API esté disponible en tu equipo.
