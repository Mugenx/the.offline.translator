모든 문장은 Chrome 내장 Translator API로 기기에서 번역됩니다. 번역은 브라우저 안에서 처리되며, 페이지 텍스트를 외부 번역 서비스로 넘기지 않도록 돕는 방식입니다.

FAQ

자주 묻는 질문

offline.translator는 Chrome 내장 Translator API를 사용해 Chrome 브라우저 안에서 전체 웹페이지를 번역합니다. 번역은 외부 번역 서비스를 거치지 않고 기기 내 Chrome에서 처리됩니다. 사이드 패널을 열고 대상 언어를 고르면, 스크롤할 때 보이는 텍스트가 점진적으로 번역됩니다.
예. offline.translator는 현재 무료로 사용할 수 있습니다. 지금은 유료 요금제, 구독, API key 요구사항이 없습니다.
offline.translator를 사용하려면 데스크톱 Chrome 138 이상이 필요합니다. 이 확장 프로그램은 Chrome 내장 Translation API와 Prompt API를 사용하며, 다른 브라우저에서는 사용할 수 없습니다. 향후 추가 브라우저 지원이 제공될 수 있습니다.
많은 브라우저 번역 도구는 페이지 내용을 원격 서비스로 보내 처리합니다. offline.translator는 Chrome 안에서 온디바이스 AI로 번역을 처리하며, 스마트 캐시, AI 최적화, 사용자 정의 용어집 레이어, 페이지별 뷰포트 제어도 함께 제공합니다.
offline.translator는 외부 번역 서비스 대신 기기 내 Chrome에서 번역을 처리하도록 설계되어 있습니다. 이런 방식은 사내 위키, 기밀 문서, 개인 이메일, 시크릿 브라우징 세션에 더 잘 맞을 수 있습니다.
offline.translator는 아랍어, 불가리아어, 벵골어, 체코어, 덴마크어, 독일어, 그리스어, 영어, 스페인어, 핀란드어, 프랑스어, 힌디어, 크로아티아어, 헝가리어, 인도네시아어, 이탈리아어, 히브리어, 일본어, 칸나다어, 한국어, 리투아니아어, 마라티어, 네덜란드어, 노르웨이어, 폴란드어, 포르투갈어, 루마니아어, 러시아어, 슬로바키아어, 슬로베니아어, 스웨덴어, 타밀어, 텔루구어, 태국어, 터키어, 우크라이나어, 베트남어, 중국어, 번체 중국어를 포함해 39개 언어를 지원합니다.
초기 번역 후에는 Chrome의 Prompt API(Gemini Nano)를 사용해 번역 결과를 후처리할 수 있습니다. Professional은 격식 있는 문체, Casual은 자연스러운 대화체, Concise는 더 짧은 출력에 적합합니다. 최적화된 번역은 다시 캐시에 저장되므로 같은 콘텐츠에 대해 두 번 최적화 비용을 치를 필요가 없습니다. 이 기능을 사용하려면 기기에서 Prompt API를 사용할 수 있어야 합니다.
