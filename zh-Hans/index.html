本地设备翻译

每一句内容都由 Chrome 内置的 Translator API 在你的设备上本地翻译。翻译过程在浏览器中完成，有助于避免把页面文本交给外部翻译服务。

your pageno serverTranslator API ● local

实时进度追踪

通过精确百分比和分段统计实时查看翻译进度。可随时在 Viewport（更快）与 All（整页）模式之间切换。

212 / 49643% ● viewport

智能翻译缓存

翻译结果会存储在 IndexedDB 中，回访时可立即复用。导航菜单和页脚等重复内容只翻译一次，之后直接从缓存读取，无需额外 API 调用。

IndexedDBcache hit ● 0 ms

AI 优化（Gemini）

可用 Chrome 的 Prompt API 对翻译结果进行后处理。支持 Professional、Casual 和 Concise 三种风格。优化后的文本会写回缓存，之后可瞬时复用。

常见问题

常见问题

offline.translator 直接在你的 Chrome 浏览器中使用 Chrome 内置的 Translator API 翻译整个网页。翻译会在 Chrome 中以本地方式处理，而不是通过外部翻译服务。打开侧边栏，选择目标语言，扩展就会在你滚动页面时逐步翻译可见文本。
是的。offline.translator 当前可免费使用。现在没有付费档位、订阅，也不需要 API key。
offline.translator 需要 桌面版 Chrome 138 或更高版本。它依赖 Chrome 内置的 Translation API 和 Prompt API，这些 API 在其他浏览器中不可用。未来可能会增加更多浏览器支持。
许多浏览器翻译工具都会把页面内容发送到远程服务处理。offline.translator 则在 Chrome 中使用本地 AI 处理翻译，同时提供智能缓存、AI 优化（Professional / Casual / Concise 风格）、自定义词汇表层，以及按页视口控制。
offline.translator 的设计是让翻译在你的设备上的 Chrome 中完成，而不是通过外部翻译服务。对于公司内部 wiki、机密文档、个人邮件和隐私浏览会话，这种工作方式通常更合适。
offline.translator 支持 39 种语言，包括阿拉伯语、保加利亚语、孟加拉语、捷克语、丹麦语、德语、希腊语、英语、西班牙语、芬兰语、法语、印地语、克罗地亚语、匈牙利语、印度尼西亚语、意大利语、希伯来语、日语、卡纳达语、韩语、立陶宛语、马拉地语、荷兰语、挪威语、波兰语、葡萄牙语、罗马尼亚语、俄语、斯洛伐克语、斯洛文尼亚语、瑞典语、泰米尔语、泰卢固语、泰语、土耳其语、乌克兰语、越南语、中文和繁体中文。
在初始翻译完成后，你可以使用 Chrome 的 Prompt API（Gemini Nano）对译文进行后处理。可选择 Professional 用于正式语气，Casual 用于自然对话风格，或 Concise 用于更短输出。优化后的翻译会写回缓存，因此你无需为同一段内容重复支付优化成本。此功能要求你的设备支持 Prompt API。
