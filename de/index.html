So funktioniert's

In 30 Sekunden startklar

Einmal installieren, Seitenleiste öffnen, Sprache wählen. Die Übersetzung startet sofort und hält beim Scrollen Schritt.

Anleitung lesen
Einmal einrichtenJede Seite
  1. 01

    Erweiterung installieren

    Füge offline.translator mit einem Klick zu Chrome hinzu. Kein Konto. Keine Registrierung. Keine unnötigen Berechtigungen.

  2. 02

    Seitenleiste öffnen

    Klicke auf das Erweiterungssymbol, um die Seitenleiste zu öffnen. Wähle deine Zielsprache im Dropdown To – mehr ist nicht nötig.

  3. 03

    In deiner Sprache lesen

    Die Übersetzung startet sofort und läuft im Hintergrund. Beobachte den Live-Fortschrittsbalken und übersetze neue Inhalte beim Scrollen nach Bedarf.

Funktionen

Alles, was du brauchst.

Entwickelt für Entwickler, Forschende und alle, die das Web in einer zweiten Sprache lesen.

On-Device-Übersetzung

Jeder Satz wird von Chromes integrierter Translator API direkt auf deinem Gerät übersetzt. Die Übersetzung läuft im Browser und hilft dabei, Seitentext nicht an externe Übersetzungsdienste weiterzureichen.

your pageno serverTranslator API ● local

Live-Fortschrittsanzeige

Verfolge den Übersetzungsfortschritt live mit exakter Prozentanzeige und Aufschlüsselung nach Segmenten. Wechsle jederzeit zwischen Viewport (schnell) und All (ganze Seite).

212 / 49643% ● viewport

Smarter Übersetzungscache

Übersetzungen werden in IndexedDB gespeichert und bei späteren Besuchen sofort wiederverwendet. Wiederkehrende Inhalte wie Navigation und Footer werden einmal übersetzt und anschließend aus dem Cache geladen – ohne zusätzliche API-Aufrufe.

IndexedDBcache hit ● 0 ms

KI-Optimierung (Gemini)

Nachbearbeitung von Übersetzungen mit Chromes Prompt API. Wähle zwischen Professional, Casual oder Concise. Optimierter Text wird zurück in den Cache geschrieben und ist sofort wieder verfügbar.

v1 casualv2 Professional ●

Für wen

Gemacht für Menschen, die das Web in mehr als einer Sprache lesen

Entwickler

Lies fremdsprachige Dokus, Stack-Overflow-Threads und Tech-Blogs, ohne Inhalte in einen Übersetzungsdienst zu kopieren. Sensibler Code und interne Dokumente bleiben von externen Servern fern.

Forschende & Akademiker

Übersetze komplette Forschungspapiere, Artikel und akademische Quellen, ohne die Seite zu verlassen. Die Glossarebene sorgt für konsistente Übersetzung von Fachbegriffen.

Datenschutzbewusste Nutzer

Lies internationale Nachrichten, Social Media und persönliche Kommunikation, ohne Leseverhalten oder private Inhalte an Übersetzungs-APIs von Dritten zu senden.

Globale Teams

Prüfe Wettbewerberseiten, Partnerdokumentation oder kundenorientierte Inhalte aus jeder Sprache, ohne einen separaten Übersetzungsworkflow zu starten.

Warum offline.translator

Browserübersetzung mit Fokus auf Privatsphäre auf dem Gerät

So schneidet es im Vergleich ab, wenn Seiten an einen Cloud-Übersetzer gesendet werden oder die Übersetzen-Schaltfläche des Browsers genutzt wird.

FAQ

Häufig gestellte Fragen

offline.translator übersetzt komplette Webseiten direkt in deinem Chrome-Browser mit Chromes integrierter Translator API. Die Übersetzung wird in Chrome auf deinem Gerät verarbeitet, statt einen externen Übersetzungsdienst zu nutzen. Öffne die Seitenleiste, wähle eine Zielsprache, und die Erweiterung übersetzt sichtbaren Text beim Scrollen schrittweise.
Ja. offline.translator kann derzeit kostenlos genutzt werden. Aktuell gibt es keine bezahlten Tarife, Abos oder API-key-Anforderungen.
offline.translator erfordert Chrome 138 oder neuer auf dem Desktop. Es nutzt Chromes integrierte Translation API und Prompt API, die in anderen Browsern nicht verfügbar sind. Zusätzliche Browserunterstützung könnte künftig folgen.
Viele Browser-Übersetzungstools leiten Seiteninhalte zur Verarbeitung an einen entfernten Dienst weiter. offline.translator verarbeitet Übersetzungen dagegen in Chrome mit On-Device-KI und bietet zusätzlich smartes Caching, KI-Optimierung, eine benutzerdefinierte Glossarebene und Viewport-Steuerung pro Seite.
offline.translator ist darauf ausgelegt, Übersetzungen in Chrome auf deinem Gerät zu verarbeiten, statt einen externen Übersetzungsdienst einzubinden. Dieser Ablauf kann gut zu internen Wikis, vertraulichen Dokumenten, persönlichen E-Mails und privatem Surfen passen.
offline.translator unterstützt 39 Sprachen, darunter Arabisch, Bulgarisch, Bangla, Tschechisch, Dänisch, Deutsch, Griechisch, Englisch, Spanisch, Finnisch, Französisch, Hindi, Kroatisch, Ungarisch, Indonesisch, Italienisch, Hebräisch, Japanisch, Kannada, Koreanisch, Litauisch, Marathi, Niederländisch, Norwegisch, Polnisch, Portugiesisch, Rumänisch, Russisch, Slowakisch, Slowenisch, Schwedisch, Tamil, Telugu, Thai, Türkisch, Ukrainisch, Vietnamesisch, Chinesisch und traditionelles Chinesisch.
Nach der ersten Übersetzung kannst du mit Chromes Prompt API (Gemini Nano) Übersetzungen nachbearbeiten. Wähle Professional für formelle Sprache, Casual für einen natürlichen Gesprächston oder Concise für kürzere Ausgaben. Optimierte Übersetzungen werden wieder im Cache gespeichert, sodass du die Optimierungskosten nicht zweimal für denselben Inhalt zahlst. Diese Funktion setzt verfügbare Prompt API auf deinem Gerät voraus.
