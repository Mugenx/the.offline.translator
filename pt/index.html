Features

Everything you need.
Nothing you don't.

Built for developers, researchers, and anyone who reads the web in a second language.

On-Device Translation

Every sentence is translated by Chrome's built-in Translator API running locally on your machine. Translation happens in your browser, helping keep page text off external translation services.

Real-Time Progress Tracking

Watch translation progress live with a precise percentage counter and segment-by-segment breakdown. Switch between Viewport (fast) and All (full page) modes on the fly.

Smart Translation Cache

Translations are stored in IndexedDB and reused instantly on return visits. Repeated content like navigation menus and footers is translated once and served from cache — zero extra API calls.

AI Optimization (Gemini)

Post-process translations with Chrome's Prompt API. Choose from Professional, Casual, or Concise styles. Optimized text is saved back to cache for instant reuse.

40+ Languages Supported

Arabic, Chinese, French, German, Hindi, Japanese, Korean, Portuguese, Russian, Spanish, and many more. Customize exactly which languages appear in the From and To dropdowns.

Plugins & Add-ons

Extend translation with optional plugins: hover preview for glossary terms, targeted search bridge for query re-translation, and a custom glossary layer with Aho-Corasick term matching.
