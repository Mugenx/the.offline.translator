Como funciona

Feito para programadores, investigadores e qualquer pessoa que leia a web numa segunda língua.

Tradução no dispositivo

Cada frase é traduzida pela Translator API integrada do Chrome no seu dispositivo. A tradução acontece no navegador, ajudando a evitar que o texto da página seja encaminhado para um serviço de tradução externo.

your pageno serverTranslator API ● local

Acompanhamento em tempo real

Acompanhe o progresso da tradução em direto com percentagem precisa e detalhe por segmentos. Alterne entre os modos Viewport (rápido) e All (página completa) a qualquer momento.

212 / 49643% ● viewport

Cache inteligente de tradução

As traduções são guardadas em IndexedDB e reutilizadas de imediato em visitas futuras. Conteúdo repetido, como menus e rodapés, é traduzido uma vez e depois servido a partir da cache, sem chamadas extra à API.

IndexedDBcache hit ● 0 ms

Otimização por IA (Gemini)

Faça pós-processamento das traduções com a Prompt API do Chrome. Escolha entre os estilos Professional, Casual ou Concise. O texto otimizado é guardado novamente na cache para reutilização instantânea.

v1 casualv2 Professional ●

Quem usa

Feito para quem lê a web em mais do que uma língua

Programadores

Leia documentação em língua estrangeira, tópicos do Stack Overflow e blogues técnicos sem copiar e colar num serviço de tradução. Código sensível e documentos internos ficam longe de servidores externos.

Investigadores e académicos

Traduza artigos científicos, textos e fontes académicas completas sem sair da página. A camada de glossário garante a tradução consistente de termos específicos da área.

Utilizadores preocupados com a privacidade

Navegue por notícias internacionais, redes sociais e comunicações pessoais sem enviar os seus hábitos de leitura ou conteúdo privado para APIs de tradução de terceiros.

Equipas globais

Reveja sites de concorrentes, documentação de parceiros ou conteúdo para clientes em qualquer idioma sem iniciar um fluxo de tradução separado.

FAQ

Perguntas frequentes

O offline.translator traduz páginas web inteiras diretamente no seu navegador Chrome usando a Translator API integrada do Chrome. A tradução é processada no Chrome no seu dispositivo, em vez de passar por um serviço de tradução externo. Abra o painel lateral, escolha um idioma de destino e a extensão traduz progressivamente o texto visível à medida que faz scroll.
Sim. O offline.translator pode ser usado gratuitamente neste momento. Atualmente não existem planos pagos, subscrições nem requisitos de API key.
O offline.translator requer Chrome 138 ou superior no computador. Usa a Translation API e a Prompt API integradas do Chrome, que não estão disponíveis noutros navegadores. O suporte a navegadores adicionais poderá ser adicionado no futuro.
Muitas ferramentas de tradução no navegador enviam o conteúdo da página para um serviço remoto para processamento. O offline.translator processa a tradução no Chrome com IA no dispositivo e inclui cache inteligente, otimização por IA, uma camada de glossário personalizada e controlos de viewport por página.
O offline.translator foi concebido para processar a tradução no Chrome no seu dispositivo, em vez de depender de um serviço de tradução externo. Este fluxo pode adequar-se bem a wikis internas, documentos confidenciais, e-mails pessoais e sessões de navegação privada.
O offline.translator suporta 39 idiomas, incluindo árabe, búlgaro, bengali, checo, dinamarquês, alemão, grego, inglês, espanhol, finlandês, francês, hindi, croata, húngaro, indonésio, italiano, hebraico, japonês, canarês, coreano, lituano, marata, neerlandês, norueguês, polaco, português, romeno, russo, eslovaco, esloveno, sueco, tâmil, telugu, tailandês, turco, ucraniano, vietnamita, chinês e chinês tradicional.
Depois da tradução inicial, pode usar a Prompt API do Chrome (Gemini Nano) para pós-processar as traduções. Escolha Professional para linguagem formal, Casual para um tom conversacional natural, ou Concise para uma saída mais curta. As traduções otimizadas são guardadas novamente na cache, para que não pague o custo de otimização duas vezes pelo mesmo conteúdo. Esta funcionalidade requer disponibilidade da Prompt API na sua máquina.
