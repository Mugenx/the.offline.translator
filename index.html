Features

Everything you need.
Nothing you don't.

Built for developers, researchers, and anyone who reads the web in a second language.

On-Device Translation

Every sentence is translated by Chrome's built-in Translator API running locally on your machine. Translation happens in your browser, keeping page content off external translation services.

Real-Time Progress Tracking

Watch translation progress live with a precise percentage counter and segment-by-segment breakdown. Switch between Viewport (fast) and All (full page) modes on the fly.

Smart Translation Cache

Translations are stored in IndexedDB and reused instantly on return visits. Repeated content like navigation menus and footers is translated once and loaded from cache — zero extra API calls.

AI Optimization (Gemini)

Post-process translations with Chrome's Prompt API. Choose from Professional, Casual, or Concise styles. Optimized text is saved back to cache for instant reuse.

35+ Languages Supported

Arabic, Chinese, French, German, Hindi, Japanese, Korean, Portuguese, Russian, Spanish, and many more. Customize exactly which languages appear in the From and To dropdowns.

Plugins & Add-ons

Extend translation with optional plugins: hover preview for glossary terms, search bridge for re-translating queries, and a custom glossary layer with Aho-Corasick term matching.

How It Works

Up and running in 30 seconds

  1. 01

    Install the extension

    Add offline.translator to Chrome in one click. No account. No signup. No permissions beyond what's needed.

  3. 03

    Read in your language

    Translation starts immediately and runs in the background. Watch the live progress bar. Scroll to translate new content on demand — it translates automatically as you browse.
