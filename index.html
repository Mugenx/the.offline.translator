Features

Built for developers, researchers, and anyone who reads the web in a second language.

On-Device Translation

Every sentence is translated by Chrome's built-in Translator API running locally on your machine. Translation happens in your browser, keeping page content off external translation services.

your pageno serverTranslator API ● local

Real-Time Progress Tracking

Watch translation progress live with a precise percentage counter and segment-by-segment breakdown. Switch between Viewport (fast) and All (full page) modes on the fly.

212 / 49643% ● viewport

Smart Translation Cache

Translations are stored in IndexedDB and reused instantly on return visits. Repeated content like navigation menus and footers is translated once and loaded from cache — zero extra API calls.

IndexedDBcache hit ● 0 ms

AI Optimization (Gemini)

Post-process translations with Chrome's Prompt API. Choose from Professional, Casual, or Concise styles. Optimized text is saved back to cache for instant reuse.

FAQ

Frequently asked questions

offline.translator translates entire webpages directly in Chrome, using Chrome's built-in Translator API. Everything happens on your device — no external servers involved. Open the side panel, pick a target language, and the extension progressively translates visible text as you scroll.
Yes. offline.translator is free to use. There are no paid tiers, subscriptions, or API key requirements.
offline.translator requires Chrome 138 or newer on desktop. It uses Chrome's built-in Translation API and Prompt API which are not available in other browsers. Support for additional browsers may be added in the future.
Many browser translation tools route page content through a remote service for processing. offline.translator handles translation in Chrome using on-device AI, and also includes smart caching, AI optimization (Professional/Casual/Concise styles), a custom glossary layer, and per-page viewport controls.
offline.translator runs translations locally on your device, so your content never touches a third-party service. It's well-suited for internal company wikis, confidential documents, personal email, and private browsing.
offline.translator supports 39 languages including Arabic, Bulgarian, Bangla, Czech, Danish, German, Greek, English, Spanish, Finnish, French, Hindi, Croatian, Hungarian, Indonesian, Italian, Hebrew, Japanese, Kannada, Korean, Lithuanian, Marathi, Dutch, Norwegian, Polish, Portuguese, Romanian, Russian, Slovak, Slovenian, Swedish, Tamil, Telugu, Thai, Turkish, Ukrainian, Vietnamese, Chinese, and Traditional Chinese.
After the initial translation, you can refine the results using Chrome's Prompt API (Gemini Nano). Choose Professional for formal language, Casual for a natural tone, or Concise for shorter output. Refined translations are saved to cache, so repeated content loads instantly without re-processing. This feature requires Prompt API availability on your machine.
