Come funziona

Pronto in 30 secondi

Installa una volta, apri il pannello laterale, scegli una lingua. La traduzione parte subito e segue lo scorrimento.

Leggi la guida
Da configurare una voltaOgni pagina
  1. 01

    Installa l'estensione

    Aggiungi offline.translator a Chrome con un clic. Nessun account. Nessuna registrazione. Nessun permesso oltre al necessario.

  2. 02

    Apri il pannello laterale

    Fai clic sull'icona dell'estensione per aprire il pannello laterale. Seleziona la lingua di destinazione dal menu To e hai finito.

  3. 03

    Leggi nella tua lingua

    La traduzione parte subito e continua in background. Guarda la barra di avanzamento in tempo reale e scorri per tradurre gradualmente i nuovi contenuti.

scorri → traduci altro

Pensato per sviluppatori, ricercatori e per chiunque legga il web in una seconda lingua.

Traduzione sul dispositivo

Ogni frase viene tradotta tramite la Translator API integrata di Chrome sul tuo dispositivo. La traduzione avviene nel browser e aiuta a evitare di inoltrare il testo della pagina a un servizio di traduzione esterno.

your pageno serverTranslator API ● local

Monitoraggio in tempo reale

Segui l'avanzamento della traduzione dal vivo con percentuale precisa e dettaglio per segmento. Passa in qualsiasi momento tra Viewport (veloce) e All (pagina intera).

212 / 49643% ● viewport

Cache intelligente delle traduzioni

Le traduzioni vengono salvate in IndexedDB e riutilizzate all'istante nelle visite successive. I contenuti ripetuti, come menu e footer, vengono tradotti una sola volta e poi serviti dalla cache, senza chiamate API extra.

IndexedDBcache hit ● 0 ms

Ottimizzazione IA (Gemini)

Rifinisci le traduzioni con la Prompt API di Chrome. Scegli tra gli stili Professional, Casual o Concise. Il testo ottimizzato viene salvato di nuovo nella cache per essere riutilizzato subito.

v1 casualv2 Professional ●

Chi lo usa

Progettato per chi legge il web in più di una lingua

Sviluppatori

Leggi documentazione in lingua straniera, thread di Stack Overflow e blog tecnici senza copiare e incollare in un servizio di traduzione. Codice sensibile e documenti interni restano lontani da server esterni.

Ricercatori e accademici

Traduci interi paper, articoli e fonti accademiche senza lasciare la pagina. Il livello glossario garantisce coerenza nella traduzione dei termini specialistici.

Utenti attenti alla privacy

Consulta notizie internazionali, social media e comunicazioni personali senza inviare le tue abitudini di lettura o i tuoi contenuti privati ad API di traduzione di terze parti.

Team globali

Rivedi siti dei concorrenti, documentazione dei partner o contenuti rivolti ai clienti in qualsiasi lingua senza avviare un workflow di traduzione separato.

FAQ

Domande frequenti

offline.translator traduce intere pagine web direttamente nel tuo browser Chrome usando la Translator API integrata di Chrome. La traduzione viene elaborata in Chrome sul tuo dispositivo, invece di passare da un servizio di traduzione esterno. Apri il pannello laterale, scegli una lingua di destinazione e l'estensione tradurrà progressivamente il testo visibile mentre scorri.
Sì. offline.translator è attualmente gratuito da usare. Al momento non ci sono piani a pagamento, abbonamenti o requisiti di API key.
offline.translator richiede Chrome 138 o versione successiva su desktop. Usa la Translation API e la Prompt API integrate di Chrome, che non sono disponibili in altri browser. In futuro potrebbe essere aggiunto il supporto per altri browser.
Molti strumenti di traduzione nel browser inviano il contenuto della pagina a un servizio remoto per l'elaborazione. offline.translator invece gestisce la traduzione in Chrome con IA sul dispositivo e include anche cache intelligente, ottimizzazione AI, un livello di glossario personalizzato e controlli viewport per pagina.
offline.translator è progettato per elaborare la traduzione in Chrome sul tuo dispositivo, invece di appoggiarsi a un servizio di traduzione esterno. Questo flusso può adattarsi bene a wiki interne, documenti riservati, email personali e sessioni di navigazione privata.
offline.translator supporta 39 lingue, tra cui arabo, bulgaro, bangla, ceco, danese, tedesco, greco, inglese, spagnolo, finlandese, francese, hindi, croato, ungherese, indonesiano, italiano, ebraico, giapponese, kannada, coreano, lituano, marathi, olandese, norvegese, polacco, portoghese, rumeno, russo, slovacco, sloveno, svedese, tamil, telugu, thai, turco, ucraino, vietnamita, cinese e cinese tradizionale.
Dopo la traduzione iniziale, puoi usare la Prompt API di Chrome (Gemini Nano) per post-elaborare le traduzioni. Scegli Professional per un linguaggio formale, Casual per un tono conversazionale naturale o Concise per un output più breve. Le traduzioni ottimizzate vengono salvate di nuovo nella cache, così non paghi il costo di ottimizzazione due volte per lo stesso contenuto. Questa funzione richiede la disponibilità della Prompt API sul tuo computer.
