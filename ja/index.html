実際のスクリーンショット。実際のページ。実際の翻訳。すべてオンデバイスです。

使い方

30秒で使い始められます

一度インストールして、サイドパネルを開き、言語を選ぶだけ。翻訳はすぐに始まり、スクロールに合わせて進みます。

ガイドを読む
最初の一度だけすべてのページで
  1. 01

    拡張機能をインストール

    offline.translator をワンクリックで Chrome に追加。アカウント不要、登録不要、必要以上の権限も求めません。

  2. 02

    サイドパネルを開く

    拡張機能アイコンをクリックしてサイドパネルを開きます。To ドロップダウンで翻訳先言語を選ぶだけです。

  3. 03

    自分の言語で読む

    翻訳はすぐに始まり、バックグラウンドで進行します。ライブ進捗バーを確認しながら、スクロールに合わせて新しいコンテンツを順次翻訳できます。

スクロール → さらに翻訳

オンデバイス翻訳

各文章は Chrome 内蔵の Translator API により端末上で翻訳されます。翻訳はブラウザ内で処理され、ページのテキストを外部の翻訳サービスに渡しにくい設計です。

your pageno serverTranslator API ● local

リアルタイム進捗トラッキング

正確なパーセンテージ表示とセグメント別の内訳で、翻訳の進み具合をリアルタイムに確認できます。Viewport（高速）と All（全ページ）モードはその場で切り替え可能です。

212 / 49643% ● viewport

スマート翻訳キャッシュ

翻訳結果は IndexedDB に保存され、再訪時に即座に再利用されます。ナビゲーションやフッターのような繰り返しコンテンツは一度だけ翻訳され、以後はキャッシュから配信されるため、追加の API 呼び出しは不要です。

IndexedDBcache hit ● 0 ms

AI最適化（Gemini）

Chrome の Prompt API で翻訳結果を後処理できます。Professional、Casual、Concise の各スタイルを選択可能。最適化済みテキストはキャッシュに保存され、次回は即座に再利用できます。

v1 casualv2 Professional ●

プラグインとアドオン

FAQ

よくある質問

offline.translator は Chrome 内蔵の Translator API を使って、ブラウザ内で Web ページ全体を翻訳します。翻訳は外部の翻訳サービスを経由せず、Chrome 内でオンデバイス処理されます。サイドパネルを開いて対象言語を選ぶと、スクロールに合わせて表示テキストが順次翻訳されます。
はい。offline.translator は現在無料で利用できます。現時点では有料プラン、サブスクリプション、API key は必要ありません。
offline.translator は デスクトップ版 Chrome 138 以降 が必要です。Chrome 内蔵の Translation API と Prompt API を利用しており、これらは他のブラウザでは利用できません。今後、追加ブラウザをサポートする可能性はあります。
多くのブラウザ翻訳ツールは、ページ内容をリモートサービスに送って処理します。offline.translator は Chrome 上のオンデバイス AI で翻訳を処理し、スマートキャッシュ、AI 最適化（Professional / Casual / Concise）、カスタム用語集レイヤー、ページごとのビューポート制御も備えています。
offline.translator は、外部の翻訳サービスを経由せず、端末上の Chrome で翻訳を処理するよう設計されています。このワークフローは、社内 wiki、機密文書、個人メール、プライベートブラウジングにも向いています。
offline.translator は、アラビア語、ブルガリア語、ベンガル語、チェコ語、デンマーク語、ドイツ語、ギリシャ語、英語、スペイン語、フィンランド語、フランス語、ヒンディー語、クロアチア語、ハンガリー語、インドネシア語、イタリア語、ヘブライ語、日本語、カンナダ語、韓国語、リトアニア語、マラーティー語、オランダ語、ノルウェー語、ポーランド語、ポルトガル語、ルーマニア語、ロシア語、スロバキア語、スロベニア語、スウェーデン語、タミル語、テルグ語、タイ語、トルコ語、ウクライナ語、ベトナム語、中国語、繁体字中国語を含む39の言語に対応しています。
初回翻訳のあとで、Chrome の Prompt API（Gemini Nano）を使って訳文を後処理できます。Professional はフォーマル向け、Casual は自然な会話調、Concise は短めの出力向けです。最適化済み翻訳はキャッシュに保存されるため、同じ内容に対して二度コストを払う必要はありません。この機能を使うには端末で Prompt API が利用可能である必要があります。
