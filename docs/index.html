Get started in Chrome

Install offline.translator, open the side panel and pick a language. Translation runs in Chrome on your device, with no account and no API key.

Check your Chrome

offline.translator needs Chrome 138 or newer on desktop. It uses Chrome's built-in Translator API, and optionally the Prompt API with Gemini Nano. Other browsers do not offer these APIs yet.

Chrome versionchrome://version — 138 or newer
Translator modelschrome://on-device-translation-internals — language packs on this device
Gemini Nanochrome://on-device-internals — optional, for AI polish

Install the extension

Add offline.translator from the Chrome Web Store. It is free, with no signup, no subscription and no API key.

Install on Chrome — Free

Open the side panel

Click the offline.translator icon in Chrome's toolbar to open the side panel. Choose the language you want to read in from the To dropdown. From can stay on auto-detect.

Both lists can be trimmed to the languages you actually use, so picking one stays quick.

Read the page

Translation starts right away and runs in the background. In Viewport mode it translates what is on screen and keeps up as you scroll. Switch to All to translate the whole page in one pass.

The first time you use a language pair, Chrome may need to download its translation model. After that the pair runs locally. You can see which language packs are on your device at chrome://on-device-translation-internals.

Polish with Gemini Nano

Optional. If the Prompt API is available on your machine, you can refine a translation in Professional, Casual or Concise style. Refined text is saved to the cache, so the same content loads instantly next time.
